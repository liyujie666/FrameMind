# FrameMind 输入框快捷功能设计文档

## 概述

在 AI 对话框输入区新增了两个实用的快捷功能按钮，提升视频分析的用户体验。

## 新增功能

### 1. 💡 快速提问（预设问题模板）

**功能说明：**
点击"快速提问"按钮，会弹出一个下拉菜单，包含常用的视频分析问题模板。用户选择后，问题会自动填充到输入框中。

**预设模板列表：**
- 📝 总结这个视频的主要内容
- 🎬 这一段发生了什么？
- 🔍 识别画面中的物体
- 📄 提取画面中的文字
- 🚶 分析画面中的人物动作
- ⚖️ 对比这几帧的差异

**使用场景：**
- 快速开始视频分析，无需手动输入
- 标准化问题格式，获得更好的 AI 响应
- 降低新用户的使用门槛

**技术实现：**
- 使用 QMenu 实现下拉菜单
- 根据主题服务动态调整菜单样式
- 点击模板后自动清空输入框并填充模板文本
- 光标自动定位到文本末尾，方便继续编辑

### 2. ⏱ 时间段选择器

**功能说明：**
点击"时间段"按钮，会打开一个对话框，允许用户选择要分析的视频时间范围。

**主要功能：**
- **手动输入：** 可以精确输入开始时间和结束时间（单位：秒）
- **快速选择：** 提供快捷按钮：
  - 前后 5 秒
  - 前后 10 秒
  - 前后 30 秒
  - 前后 60 秒
- **智能默认值：** 开始时间默认为当前播放位置，结束时间默认为当前位置+10秒
- **边界保护：** 自动限制在视频有效时长范围内

**使用场景：**
- 分析特定时间段的内容
- 批量提取时间段内的关键帧
- 针对某个场景进行深入分析

**技术实现：**
- 使用 QDialog 实现模态对话框
- QSpinBox 提供时间输入，带单位后缀
- 快速选择按钮基于当前播放位置计算
- 确认后在输入框插入时间范围标记：`[时间段 00:30-01:00]`
- 发出 `timeRangeRequested` 信号，供上层处理

## UI 设计特点

### 按钮风格统一
所有快捷按钮采用统一的设计语言：
- 圆角胶囊形状 (border-radius: 14px)
- 边框 + 半透明背景
- 悬停时突出显示（边框变为主题色）
- 禁用时自动灰化

### 主题自适应
- 所有组件完全支持亮色/暗色主题切换
- 使用 ThemeService 统一管理颜色
- 菜单和对话框样式随主题动态调整

### 交互友好
- Emoji 图标增加视觉识别度
- 悬停提示（tooltip）清晰说明功能
- 快捷按钮在流式传输时自动禁用
- 对话框提供取消选项，避免误操作

## 使用示例

### 在主窗口中连接信号

```cpp
// 设置视频信息（在视频打开时调用）
chatInputWidget->setVideoDuration(videoDurationMs);

// 更新当前时间戳（在播放器位置变化时调用）
chatInputWidget->setCurrentTimestamp(currentTimestampMs);

// 处理时间段请求
connect(chatInputWidget, &ChatInputWidget::timeRangeRequested,
        this, [this](int64_t startMs, int64_t endMs) {
            // 在这里可以批量获取该时间段的关键帧
            // 或者传递给 AI 服务进行时间段分析
            qDebug() << "用户选择分析时间段:" << startMs << "-" << endMs;
        });
```

## 未来扩展

### 可能的增强功能：
1. **自定义模板** - 允许用户保存和管理自己的问题模板
2. **批量帧提取** - 时间段选择后自动提取关键帧（基于场景检测）
3. **历史时间戳** - 显示之前分析过的时间点，快速跳转
4. **场景快速选择** - 基于已索引的场景信息，提供场景级的快速选择
5. **智能推荐** - 根据视频内容推荐合适的问题模板

## 注意事项

1. **性能考虑：** 时间段分析可能涉及大量帧的处理，建议在实现时添加进度提示
2. **用户体验：** 预设模板应该根据用户反馈持续优化
3. **国际化：** 所有文本都使用 `tr()` 包装，支持多语言
4. **错误处理：** 时间段选择应该验证输入有效性（开始 < 结束）
