# FrameMind 快捷功能使用指南

## 功能位置

在 AI 对话框的输入框上方，新增了三个快捷按钮：

```
┌─────────────────────────────────────────────────────┐
│  AI Chat                                    + × │
├─────────────────────────────────────────────────────┤
│                                                     │
│  [消息历史显示区域]                                  │
│                                                     │
├─────────────────────────────────────────────────────┤
│  📷 添加当前帧   ⏱ 时间段   💡 快速提问              │  ← 新增按钮行
│                                                     │
│  ┌───────────────────────────────────────────────┐ │
│  │ 输入问题…（Enter 发送，Shift+Enter 换行）      │ │
│  │                                               │ │
│  └───────────────────────────────────────────────┘ │
│                                        [发送]       │
└─────────────────────────────────────────────────────┘
```

## 1. 📷 添加当前帧（原有功能）

点击后将当前视频画面添加到消息中，与问题一起发送给 AI。

## 2. ⏱ 时间段选择器（新功能）

### 使用步骤：

**步骤 1：点击"时间段"按钮**

弹出时间段选择对话框：

```
┌────────────────────────────────────────┐
│  选择分析时间范围                       │
├────────────────────────────────────────┤
│                                        │
│  选择要分析的视频时间段：               │
│                                        │
│  开始时间:  [  30  ] 秒                │
│  结束时间:  [  40  ] 秒                │
│                                        │
│  快速选择：                             │
│  [前后5秒] [前后10秒] [前后30秒] [前后60秒] │
│                                        │
│                    [确定]  [取消]      │
└────────────────────────────────────────┘
```

**步骤 2：输入时间或使用快速选择**

- **手动输入：** 直接在输入框中输入秒数
- **快速选择：** 点击快捷按钮，自动计算当前位置前后N秒

**步骤 3：确认后效果**

输入框中会自动插入时间段标记：

```
[时间段 00:30-00:40] 这一段发生了什么？
```

然后可以继续输入你的问题。

### 应用场景：

- 🎯 **精确分析：** "分析 00:30-01:00 这段时间的内容"
- 🔍 **场景研究：** "总结开场 0:00-0:30 的主要信息"
- 📊 **对比分析：** "对比前半段和后半段的差异"

## 3. 💡 快速提问（新功能）

### 使用步骤：

**步骤 1：点击"快速提问"按钮**

弹出问题模板菜单：

```
┌──────────────────────────────┐
│ 📝  总结这个视频的主要内容    │
│ 🎬  这一段发生了什么？        │
│ 🔍  识别画面中的物体          │
│ 📄  提取画面中的文字          │
│ 🚶  分析画面中的人物动作      │
│ ⚖️  对比这几帧的差异          │
└──────────────────────────────┘
```

**步骤 2：点击任意模板**

问题会自动填充到输入框中，你可以：
- 直接发送
- 或者继续编辑补充细节

### 各模板的使用说明：

| 模板 | 适用场景 | 建议操作 |
|------|----------|----------|
| 📝 总结视频主要内容 | 快速了解整个视频 | 无需添加帧，直接发送 |
| 🎬 这一段发生了什么 | 分析特定片段 | 配合时间段选择器使用 |
| 🔍 识别画面中的物体 | 分析静态画面 | 先添加当前帧，再发送 |
| 📄 提取画面中的文字 | OCR 识别需求 | 先添加包含文字的帧 |
| 🚶 分析人物动作 | 动作识别 | 添加关键动作帧 |
| ⚖️ 对比这几帧的差异 | 帧对比分析 | 先添加多个帧（2-4个） |

## 组合使用示例

### 示例 1：分析特定场景的物体

1. 播放视频到目标位置（如 01:23）
2. 点击 **📷 添加当前帧**
3. 点击 **💡 快速提问** → 选择"🔍 识别画面中的物体"
4. 发送

结果：
```
[已添加帧: image_01:23]
识别画面中的物体
```

### 示例 2：总结某个时间段

1. 播放到要分析的片段起点
2. 点击 **⏱ 时间段** → 选择"前后30秒"
3. 点击 **💡 快速提问** → 选择"🎬 这一段发生了什么？"
4. 发送

结果：
```
[时间段 00:53-01:53] 这一段发生了什么？
```

### 示例 3：对比多个场景

1. 跳转到第一个场景，点击 **📷 添加当前帧**
2. 跳转到第二个场景，点击 **📷 添加当前帧**
3. 跳转到第三个场景，点击 **📷 添加当前帧**
4. 点击 **💡 快速提问** → 选择"⚖️ 对比这几帧的差异"
5. 发送

结果：
```
[已添加帧: image_00:15]
[已添加帧: image_01:30]
[已添加帧: image_02:45]
对比这几帧的差异
```

## 快捷键提示

| 操作 | 快捷键 |
|------|--------|
| 发送消息 | Enter |
| 换行 | Shift + Enter |
| 停止生成 | 点击"停止"按钮 |

## 注意事项

### 🚫 流式传输时的限制

当 AI 正在生成回复时（显示"停止"按钮），所有快捷按钮会自动禁用：
- ~~📷 添加当前帧~~ （禁用）
- ~~⏱ 时间段~~ （禁用）
- ~~💡 快速提问~~ （禁用）

等待 AI 回复完成后，按钮会自动恢复可用状态。

### ⚠️ 时间段选择的限制

- 开始时间必须小于结束时间
- 时间范围会自动限制在视频有效时长内
- 建议单次分析的时间段不超过 2-3 分钟（避免内容过多）

### 💡 最佳实践

1. **逐步提问：** 从宽泛的总结开始，再深入到细节
2. **合理选帧：** 选择关键帧而非连续帧，避免信息冗余
3. **明确需求：** 可以在模板基础上补充具体要求
4. **利用上下文：** AI 会记住对话历史，可以追问"刚才那个场景中..."
