### 2. 场景与 ASR 时间对齐

新增：

- `src/service/rag/audio_visual_aligner.h`
- `src/service/rag/audio_visual_aligner.cpp`

实现了：

- 严格的时间区间重叠判断；
- 按语音段落入当前场景的比例排序；
- 每场景最多 8 个语音段；
- 转写内容最多 1500 字符；
- 过滤只有极少量重叠的跨场景语音；
- 返回结果恢复为时间升序，并保留原始时间戳。

长语音不会被无条件复制到每一个短场景。

---

### 3. 程序侧语义门控

门控综合以下信号：

1. 同期语音对场景时长的覆盖率；
2. 纯视觉描述与同期转写的 BGE 余弦相似度；
3. 中文 2-gram 和英文词级关键词交集；
4. 语音段横跨多个视觉场景的程度；
5. 转写文本是否短到不足以支撑关系判断。

当 BGE 不可用时，会自动退化为：

- 时间覆盖率；
- 关键词交集；
- 跨场景惩罚；

并倾向输出 `Contextual` 或 `Unknown`，而不是轻易判定 `Strong`。

### 4. 两阶段 VLM 流水线

`src/service/agent/video_analysis_service.cpp` 已改为两阶段处理。

#### 阶段一：纯视觉描述

关键帧描述 prompt 现在明确要求：

- 只描述画面中可见内容；
- 不使用音频；
- 不推测画外对话或剧情；
- 生成结果单独保存为 `visualDescription`。

#### 阶段二：音视频融合

存在同期语音时，第二次调用模型，并传入：

- 场景时间范围；
- 纯视觉描述；
- 带时间戳的同期 ASR；
- 时间覆盖率；
- BGE 相似度；
- 关键词交集；
- 跨场景跨度；
- 程序候选关系和置信度。

模型要求返回结构化 JSON：

- `relation`
- `confidence`
- `audio_type`
- `audio_summary`
- `fused_description`

融合 prompt 已加入保守归因约束：

- 不因台词姓名确认画面人物身份；
- 不把画外音归给可见人物；
- 旁白使用“旁白称”；
- 背景媒体使用“电视/广播中提到”；
- 音画无关时分别描述；
- 音频不得修改纯视觉事实；
- 证据不足时明确拒绝确认。

如果 JSON 解析失败，系统不会中断索引，而是自动退化为：

- 保留纯视觉描述；
- 保存同期转写摘要；
- 以“视觉内容 / 同期音频”形式分开描述；
- 使用程序侧门控结果。

如果没有同期语音，则直接：

```text
fusedDescription = visualDescription
```

不会产生额外的融合模型调用。

### 6. 检索按问题类型选择证据

`src/service/rag/video_rag_retriever.cpp` 已增加证据类型偏好。

例如：

- “画面中的人穿什么衣服”
  - 提升纯视觉证据；
  - 降低音频与 ASR 权重。
- “谁提到了瓶子树”
  - 提升 `SpeechSegment` 和 `SceneAudio`；
  - 降低纯视觉描述权重。
- “这一段发生了什么”
  - 优先 `SceneFused`。
- 同时涉及画面和对白
  - 不强制压制任一侧，由融合证据参与裁决。

去重逻辑也已修改：

- 同一场景的视觉、音频、融合证据视为互补证据；
- 不会再因为时间范围完全相同而互相删除；
- 只有同类证据且时间高度重叠时才去重。
